Act 1: Admin Genesis (Creating Category & Product)

Admin dashboard-la oru puthiya category & product create panni database-la save panra flow.

Step 1.1

Admin Sign-in to Control Room

Store owner http://localhost:3000/admin open panni thannoda owner account moolama login panranga.

Auth API: POST /api/auth/login
Session: aval_session (HTTP-only secure cookie)
Role: AdminUser.role = 'OWNER'

👉 Enna Pannanum (Actions)

  1. Chrome-la http://localhost:3000/admin open pannunga.
  2. Login page redirect aagum. Admin email & password kuduthu Sign-in pannunga.

👀 Enna Theriyanum (Expected)

  • Admin sidebar (Dashboard, Products, Enquiries, Settings) load aaganum.
  • Invalid password kudutha clean-ah 401 Unauthorized generic error varanum.
Step 1.2

Admin Creates a Brand New Category

Admin pudhusa "Bridal Hair Accessories" nu oru category create panranga. Name type pannale slug bridal-hair-accessories nu automatic-ah generate aagidum (manual slug input thevai illa!).

API Route: POST /api/admin/categories
DB Insert: prisma.category.create({ data: { name, slug, image } })
Slug Logic: Auto-slugified from Name: /category/bridal-hair-accessories

👉 Enna Pannanum (Actions)

  1. Admin sidebar-la "Categories" click panni "+ Add category" click pannunga.
  2. Name: Bridal Hair Accessories nu type pannunga. (Keela "Address: /category/bridal-hair-accessories" nu auto-preview theriyum!)
  3. Description: Handcrafted bridal hair clips and ornaments
  4. Click "Create category" (Slug manual-ah type panna thevai illa).

👀 Enna Theriyanum (Expected)

  • Category list-la "Bridal Hair Accessories" (Hidden - empty) nu appear aaganum.
  • Database Category table-la new record add aaganum with auto-generated slug!
Step 1.3

Admin Adds a New Product under That Category

Admin ippo andha category-kku ulla "Ruby Floral Hair Vine" nu pudhu product add panranga (Price: ₹1,999, Stock: 15).

API Route: POST /api/admin/products
DB Insert: Product (name, slug, salePricePaise: 199900, stock: 15, customisable: true)
Admin UI: app/admin/products/page.tsx

👉 Enna Pannanum (Actions)

  1. Admin sidebar-la "Products" ➔ "+ Add Product" click pannunga.
  2. Name: Ruby Floral Hair Vine, Category: select Bridal Hair Accessories.
  3. Regular Price: ₹2499, Selling Price: ₹1999.
  4. Stock: 15, Sizes: Free Size (or leave empty).
  5. Keela Options section-la "Offer name personalisation (+₹200)" checkbox-ah tick ✅ pannunga! *(Idhudhan DB-la customisable)*
  6. Click "Add product".

👀 Enna Theriyanum (Expected)

  • Product list-la pudhu product stock 15 oda save aaganum.
  • Tags-la "Personalisable" nu badge theriyanum.
  • Database-la paise value (199900) correct-ah calculate aagi insert aaganum.

Act 2: How It Automatically Appears on the Website (Storefront Sync)

Admin create panna category and product live website-la eppadi automatic-ah reflect aagudhu nu check panrom.

Step 2.1

Website Header & Home Page Auto-Sync

Normal user window-la http://localhost:3000 open panrom. Admin add panna category header-la varudha nu check panrom.

Data Fetch: src/server/catalog.ts ➔ listCategories()
SSR Component: app/(storefront)/page.tsx
Sync Mechanism: Direct PostgreSQL Query (no hardcoded lists!)

👉 Enna Pannanum (Actions)

  1. Innoru tab-la http://localhost:3000 (Customer Home page) open pannunga.
  2. Top navigation menu & "Shop by Category" section paathutu refresh pannunga.

👀 Enna Theriyanum (Expected)

  • Header-la "Bridal Hair Accessories" link auto-appear aaganum.
  • "Shop by Category" tiles-la pudhu category tile 1 design oda kaattanum.
Step 2.2

Product Live in Shop & Category Page

Customer /shop or /category/bridal-hair click panranga. Admin add panna "Ruby Floral Hair Vine" anga kaatanum.

Query: prisma.product.findMany({ where: { category: { slug } } })
Price Conversion: salePricePaise (199900) / 100 = ₹1,999
Page File: app/(storefront)/shop/page.tsx

👉 Enna Pannanum (Actions)

  1. Menu-la "Shop Bridal Collection" or "Bridal Hair Accessories" click pannunga.
  2. Products list-ah paarunga.

👀 Enna Theriyanum (Expected)

  • "Ruby Floral Hair Vine" product card theriyanum.
  • Price: ₹1,999 (Strike-through ₹2,499) with "Save ₹500" badge.
  • Fake mock products flash aagama real product mattum load aaganum.
Step 2.3

Dynamic Product Detail Page (`/product/[slug]`)

Customer andha product-ah click panranga. Dedicated detail page dynamic-ah DB-la irundhu load aaganum.

Route Param: /product/ruby-floral-hair-vine
DB Lookup: prisma.product.findUnique({ where: { slug } })
Page File: app/(storefront)/product/[slug]/page.tsx

👉 Enna Pannanum (Actions)

  1. Product card-ah click panni product detail page-ku ponga.
